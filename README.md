# Copilot Instructions

Copilot instructions shared between projects such as `pepc`, `wult`, and `stats-collect`.

## Usage

Clone this repository and add its `instructions` directory to the VS Code
`chat.instructionsFilesLocations` setting, in user settings or in a `.code-workspace` file:

```jsonc
"chat.instructionsFilesLocations": {
    "~/git/copilot-instructions/instructions": true
}
```
